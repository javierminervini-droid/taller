# Plantilla de orden impresa

Para que la impresión use **tu** formato (el mismo papel/PDF que ya usan en el taller):

1. Dejá el archivo en esta carpeta, por ejemplo:
   - `orden-servicio.pdf`
   - `orden-servicio.docx`
   - o una foto/escaneo `orden-servicio.jpg` / `.png`
2. En el chat de Cursor, escribí algo como: “usá la plantilla de `plantillas/orden-servicio.pdf`”.
3. También podés **adjuntar el archivo directo en el chat**.

Con eso se replica el diseño y se rellenan automáticamente: cliente, teléfono, dirección, localidad, tipo, producto, origen, estado y fecha de carga.
